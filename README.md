# Product Data Health for Odoo 19

Free, independently installable Odoo 19 addon `cyfr_product_data_health` (LGPL-3). The addon source is in [`cyfr_product_data_health/`](cyfr_product_data_health/); see its [English guide](cyfr_product_data_health/README.md) and [Polish guide](cyfr_product_data_health/README.pl.md).

## Versions and installation

- `19.0` is the Odoo 19 maintenance branch.
- `19.0.1.0.0` is the frozen source branch for this exact addon version.
- The `cyfr_product_data_health-19.0.1.0.0` tag and [GitHub release](https://github.com/digicyfr/odoo-addon-cyfr-product-data-health/releases/tag/cyfr_product_data_health-19.0.1.0.0) identify the versioned ZIP, SHA-256 checksum, and verification evidence.

Add the repository root to an Odoo 19 custom addons path, refresh the Apps list, and install `cyfr_product_data_health`. The ZIP release contains only the addon directory. Odoo 19 Community was verified; Enterprise remains unverified. Odoo Online does not accept arbitrary server addons.

The [Digicyfr page](https://www.digicyfr.com/en/odoo/free-modules/cyfr_product_data_health) provides screenshots and download guidance. Report defects in this repository's Issues without posting credentials or customer data. This repository has fresh history containing only this free addon. The earlier [portfolio release](https://github.com/digicyfr/odoo-addons-free/releases/tag/cyfr_product_data_health-19.0.1.0.0) remains available for provenance.
